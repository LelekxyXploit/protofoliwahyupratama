PORTOFOLIO WAHYU - STRUKTUR DEPLOY VERCEL

- index.html: file utama; HTML, CSS, dan JavaScript tetap berada dalam satu file.
- images/certificates/: berisi 7 gambar sertifikat.
  - certificate-01.jpg sampai certificate-04.jpg: empat sertifikat yang baru dikirim.
  - certificate-05.jpg sampai certificate-07.jpg: tiga sertifikat tambahan yang dikirim sebelumnya.
- images/profile/profile.jpg: foto profil.
- images/qris/qris.jpg: gambar QRIS pembayaran.

Semua gambar yang dibutuhkan sekarang sudah disertakan secara lokal. HTML hanya diubah pada lokasi sumber gambar/penambahan kartu sertifikat; bagian website lainnya dipertahankan.

DEPLOY KE GITHUB / VERCEL
1. Ekstrak ZIP ini.
2. Unggah isi folder (index.html, README.txt, dan folder images) ke root repository GitHub.
3. Hubungkan repository ke Vercel atau lakukan redeploy jika sudah terhubung.
